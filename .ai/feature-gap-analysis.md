# Textory 功能缺口与产品路线盘点

> 盘点日期：2026-09-18
>
> 本文记录当前仓库的能力边界和后续候选方向，用于需求排期、版本规划和新功能 spec 起草。它不是实现承诺；新增功能仍需遵循 `.ai/spec-workflow.md`。

## 当前已有能力

- 基础富文本：标题、段落、引用、分割线、粗体、斜体、下划线、删除线、颜色、高亮、字号、对齐、缩进
- 列表：有序列表、无序列表、任务列表
- 媒体：图片、文件附件、视频、上传、粘贴、拖拽
- 高级块：代码块与语法高亮、表格、文档大纲、拖拽手柄
- 编辑辅助：Markdown 粘贴/输入、搜索替换、占位符、字数统计
- 导入导出：DOCX 导入、DOCX 导出、HTML/Markdown 能力
- 集成能力：React 组件、UMD/Standalone、features 开关、基础国际化机制

## 产品功能缺口

### P0：文档产品核心能力

#### 实时协同编辑

当前没有协同编辑、Yjs/Provider、多人光标、在线状态或离线重连能力。

候选范围：

- 多人实时编辑和冲突合并
- 用户光标与选区
- 在线成员列表
- 离线编辑与重新连接
- 协同权限控制

#### 评论、批注与审阅

当前没有评论线程、范围批注、回复、解决评论或修改建议。

候选范围：

- 文本范围评论与定位高亮
- 评论线程和回复
- 评论解决/重新打开
- 审阅模式、接受/拒绝修改

#### 版本历史与快照

当前只有撤销/重做，没有持久化版本、版本对比和恢复。

候选范围：

- 自动保存版本
- 版本列表和版本说明
- 版本 diff
- 恢复到指定版本
- 操作记录或修订记录

### P1：通用编辑器常见能力

#### PDF 导出与打印

当前已有 DOCX 导出，但 PDF 导出仍未内置。

候选范围：

- 打印样式和分页控制
- PDF 导出
- 页眉页脚
- 水印
- 长表格分页

#### Mention、标签、Emoji 与 Slash Command

当前没有明显的 `@用户`、`#标签`、`/` 命令菜单或 Emoji 选择器能力。

候选范围：

- `@mention`
- `#tag`
- Slash command 菜单
- Emoji picker
- 快捷插入模板

#### 内容嵌入扩展

当前已有图片、文件和视频，可继续补充：

- 音频
- YouTube/Bilibili/网页卡片
- iframe/embed
- PDF 预览
- Excel/CSV 导入
- Mermaid、数学公式、流程图

#### 图片体验增强

候选范围：

- 裁剪、旋转、压缩
- `alt`、标题和图注
- 对齐与文字环绕
- 多图画廊
- 上传失败重试
- CDN 和懒加载

#### 表格能力增强

候选范围：

- 单元格排序
- Excel 粘贴与格式保留
- 行列冻结
- 表格导入导出
- 单元格公式
- 更完整的键盘导航和移动端适配

#### 拼写与语法检查

候选范围：

- 浏览器拼写检查增强
- 中文错别字检查
- 英文语法检查
- 自定义词典
- 敏感词检测

### P2：平台和企业能力

#### 国际化完善

目前已有 locale 基础设施，但主要覆盖简体中文。候选范围：English、繁体中文、日文、locale 动态加载，以及日期/数字/快捷键文案国际化。

#### 可访问性（a11y）

当前属于基础支持，建议系统补齐：

- 工具栏和弹窗 ARIA label
- 键盘操作与焦点管理
- 表格键盘导航
- 图片/视频替代文本和字幕
- 屏幕阅读器语义
- 高对比度和 reduced motion

#### 移动端与触摸交互

候选范围：移动端工具栏、触摸选区、移动端表格、图片触摸缩放、虚拟键盘兼容，以及 iOS/Android 粘贴适配。

#### 权限与安全模型

候选范围：只读/编辑权限、块级权限、复制下载策略、URL 白名单、文件类型校验、XSS 过滤和审计日志。

## 工程质量与可靠性债务

- 测试覆盖率仍偏低，核心工具、扩展和 UI 组件尚有待补测项，详见 `.ai/test-backlog.md`
- 仍有性能债务：React NodeView 开销、代码块语言检测阻塞、内容全量比较等，详见 `.ai/performance-issues.md`
- 需要补齐上传失败重试、自动保存失败提示、错误监控和生产环境诊断能力
- 需要建立覆盖上传、粘贴、拖拽、表格、导入导出和 Standalone 的 E2E 测试矩阵
- 需要增加大文档基准测试和浏览器兼容性测试
- Demo 功能开关与 API 文档存在同步债务，详见 `.ai/known-debts.md`
- `comparison-tinymce.md` 的能力对比需要随功能演进定期校准

## 建议路线

### 通用开源编辑器

1. PDF/打印
2. Mention、Slash Command 和模板
3. 图片与表格体验增强
4. a11y 与移动端
5. 多语言
6. 测试与 E2E 完善

### Notion/语雀类文档编辑器

1. 实时协同
2. 评论/批注
3. 版本历史
4. 权限与审计
5. Mention、Slash Command 和模板
6. 自动保存与离线恢复

### 企业 Word 替代品

1. PDF/打印
2. DOCX 兼容性增强
3. 审阅与修订
4. 页眉页脚和分页
5. 表格增强
6. 拼写检查与可访问性

## 记录规则

- 本文只记录方向和缺口，不替代具体需求 spec。
- 选定任一功能进入开发前，应按 `.ai/specs/TEMPLATE.md` 创建 spec，并补充边界、兼容性和验收标准。
- 功能完成后，应同步更新本文、Demo/API 文档以及相关债务清单。
