Textory Standalone Demo

本目录验证 @textory/standalone 包的 UMD 产物。每个示例都是独立 HTML，复现真实 CDN 用户场景。

  • basic.html— standalone bundle，零依赖引入
  • external-react.html— externals bundle，需先引 React CDN
  • upload.html— 自定义 upload.image 适配器
  • features.html— features 开关
  • destroy.html— destroy + recreate + 失效保护

启动：pnpm --filter standalone-demo dev 或 pnpm start:standalone
构建产物路径：../../packages/standalone/dist/
