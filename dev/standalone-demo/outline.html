本页不含编辑器，只渲染 HTML + 挂 outline。编辑器产出的 HTML 套 <div class="textory"> 后注入，TextoryOutline.create() 扫描 h1-h6 自动构建 TOC。复用 outline.scss 的 class（已在 textory.min.css 里）。

第一章 入门

这是正文段落。编辑器产出的 HTML 通常包含 h1-h6、段落、列表、引用、代码块等。

1.1 安装

通过 script 标签引入 standalone bundle。

npm install @textory/editor

1.1.1 环境要求

Node.js 20+。

1.1.2 浏览器兼容

Chrome 90+ / Firefox 88+ / Safari 14+。

1.2 快速开始

创建一个 div 作为挂载点。

const instance = Textory.create(document.getElementById('editor'), {
  content: '<p>Hello</p>',
});
